-*INTRODUÇÃO*

    ● Um sistema para facilitar na organização de tarefas cotidianas, assim ajudando
pessoas a se organizarem, organizarem prazos de entrega e a lembrarem de
suas tarefas.

-*PROBLEMA*

    ● Tarefas acumuladas, prazos vencidos, entregas não feitas por falta de
organização, esquecimentos de tarefas que deveriam ser concluídas.

-*OBJETIVO DO SISTEMA*

    ● O sistema busca ajudar na organização de tarefas, para conseguir controlar
compromissos, entregas e os impactos dessas coisas no cotidiano.

-*FUNCIONALIDADES(Atuais)*

● Descreva de forma objetiva as principais funcionalidades do sistema:
● Cadastro de tarefas
● Visualização da lista de tarefas
● Marcação de tarefas como concluídas
● Descrição das tarefas

-*FUNCIONALIDADES(Futuras)*
    Proximas versões

    ● Contador de tarefas por colunas
    ● Cores por prioridade
    ● Salvar em localStorage
    ● Marcação de Prioridade
